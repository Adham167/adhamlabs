## Problem
Students used four different tools to find their schedule, rooms, and announcements.

## Architecture
- **Client:** Flutter app with offline cache.
- **API:** FastAPI service behind Nginx, JWT authentication.
- **Data:** PostgreSQL for schedules, Firebase for push notifications.

## What I built
- Designed the REST API and database schema.
- Led a team of four and ran weekly code reviews.

## Results
Tested with 120 students; average time to find a room dropped from 4 minutes to 40 seconds.
